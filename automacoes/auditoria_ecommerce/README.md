# Motor Híbrido de Auditoria Financeira E-commerce

Motor analítico construído com **Python + Pandas + OpenPyXL** para cruzamento em lote e auditoria de faturas, pedidos e repasses de mercadoria de operações de e-commerce e franquias.

## 📌 Funcionalidades
- Rastreamento e identificação automática de matrizes de dados (relatórios de ERP e consolidados de marketplace/franquia).
- Normalização de formatações financeiras complexas (moeda brasileira, zeros à esquerda, decimais fantasmas).
- Cruzamento relacional de chaves (`Pedido`, `NF`, `Fechamento`, `Repasse`).
- Cálculo automático de divergências entre valores faturados, comissões retidas e repasses efetuados.
- Geração de relatório consolidado formatado em Excel com destaque visual para divergências financeiras.
