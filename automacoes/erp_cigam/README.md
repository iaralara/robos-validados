# Automação de Gestão & Conciliação no ERP Cigam

Robô em **Python + Selenium** para automação de rotinas no sistema de gestão corporativo **Cigam Gestor**, focado na extração unificada de pagamentos, conciliação multi-lojas e atualização em nuvem.

## 📌 Funcionalidades
- Download em lote de relatórios de pagamentos e fechamentos diários para dezenas de filiais em uma única sessão.
- Navegação resiliente com clique forçado via JavaScript e detecção inteligente de renderização DOM.
- Cálculo de calendário útil considerando feriados bancários e municipais.
- Conexão com Google Drive API e Google Sheets API via Service Accounts para envio automatizado de dados às matrizes da diretoria.
