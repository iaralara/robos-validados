# Balanceamento & Reposição de Estoque Multi-Lojas

Conjunto de robôs analíticos em **Python + Pandas + OpenPyXL + Xlwings** para cálculo matemático de necessidade de estoque, balanceamento de grades e geração automatizada de ordens de transferência.

## 📌 Funcionalidades
- Leitura e consolidação de estoque disponível na matriz vs. histórico de giro por ponto de venda.
- Algoritmo de rateio proporcional respeitando embalagens mínimas (múltiplos de saquinhos/grades).
- Validação remota de status de operação via Control Room.
- Geração automatizada de ordens em formatos estruturados prontos para importação em sistemas de logística.
